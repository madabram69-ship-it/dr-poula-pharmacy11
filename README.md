## ✨ الأقسام الرئيسية

1. **Top Bar** — مواعيد العمل + العنوان + الهاتف
2. **Header** — شعار + قائمة تنقل + سلة + زر اتصال
3. **Hero** — قسم رئيسي تعريفي + إحصائيات + أزرار CTA
4. **Features Strip** — 4 ميزات رئيسية
5. **Categories** — 13 قسم دوائي
6. **Products** — 200 منتج مع بحث وفلاتر
7. **Offers** — 3 عروض وخصومات
8. **Prescription** — رفع صورة الروشتة + معاينة
9. **Contact** — عنوان + هاتف + خريطة + أزرار تواصل
10. **CTA Banner** — دعوة للتواصل
11. **Footer** — روابط + معلومات + سوشيال ميديا

## ⚙️ الوظائف المطبقة

### 🛒 سلة المشتريات
- إضافة منتجات للسلة
- زيادة / تقليل الكمية
- حذف منتج
- حساب الإجمالي تلقائياً
- إرسال الطلب عبر واتساب مع تفاصيل كاملة

### 🔍 البحث والفلترة
- بحث بالاسم أو الشركة
- فلترة حسب 13 قسم دوائي
- زر "عرض المزيد" (20 منتج في البداية)
- عداد النتائج

### 📄 رفع الروشتة
- رفع صورة (اختيار أو سحب)
- معاينة الصورة
- استبدال أو إزالة
- إدخال اسم ورقم هاتف مع تحقق
- إرسال عبر واتساب

### 📱 واتساب
- زر عائم ثابت
- أزرار في كل الأقسام
- رسائل جاهزة منسقة
- **ملاحظة:** الصور تُرفق يدوياً (قيد تقني في واتساب)

### 📞 الاتصال
- أزرار `tel:` مباشرة
- رابط خرائط Google

### 🎨 واجهة المستخدم
- تصميم متجاوب (موبايل / تابلت / كمبيوتر)
- أنيميشن خفيف
- Toast notifications
- Back to top
- مودال لتفاصيل المنتج
- حالات focus واضحة (Accessibility)
